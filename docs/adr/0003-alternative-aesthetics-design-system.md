# 0003: Alternative Aesthetics Design System (Monochrome Maximalist Bento Grid)

We adopted the Alternative Aesthetics design system (`DESIGN.md`, extracted by Inspo from alternativeaesthetics.co.uk):
- **Mode**: Light mode with high-contrast monochrome maximalism (`#ffffff`, `#000000`, `#424242`, `#7f7f7f`, `#9b9b9b`).
- **Macrostructure**: Bento Grid with fullbleed hero, logo cloud, and modular high-impact proof blocks.
- **Typography**: Titan One for bold, sculptural display headlines paired with Heebo for crisp, highly readable body typography.
- **Form Language**: 2px solid borders (`--field-border: 2px`), 8px border radius (`--border-radius-8px: 8px`), and tactile hard offset drop shadows (`4px 4px 0px #000000`).

This replaces generic dark SaaS templates with a visually unmistakable, punchy creative agency presence that stands out to high-paying enterprise and venture founders seeking bold creative and technical leadership.
